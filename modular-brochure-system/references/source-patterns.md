# 方法来源与适配边界

本 Skill 根据用户提供的一套历史宣传册及用户对其用法的解释抽象而成。公开内容仅保留方法观察、原创示意母版与虚构登记示例，未收录原稿图片、PSD、联系人、人物资料或客户标志。文件夹名称不是原稿品牌的证据。

## 用户明确的设计意图

- 封面是可批量制作和反复使用的收纳封套。
- 内页以 A4 印刷品为目标，可按需要自由组合。
- 产品资料采用正反两面，顶部和底部遵守统一版式。
- 不同产品、业务和解决方案用颜色区分，同时保持统一品牌形象。

## 实际观察

所提供的图像共有十八张，按文件分成一组封套和八组业务/概况资料：

- 七组为竖向正反图：上门服务、城市生活、信贷、众筹、外卖、技术概况、社区业务。
- 商业咨询一组为横向双页展开，不能直接称为现成的 A4 双面独立插页。
- 封套有外侧与内侧展开图；可见中央折线及内侧疑似口袋/折叠区域，但没有足以确认加工尺寸的刀模。
- 产品正面常用场景图与标题主视觉，背面常用紧凑深色品牌眉栏。页脚、字体层级与图标语言形成共同识别；中部随业务使用流程、功能、场景和图示。
- 业务强调色已有区别，但部分模块仍使用相近色，并非已经完成严格的一对一色谱登记。

## 不能直接继承的内容

历史文案、业务能力、案例、资质、人物信息及联系方式均不是新项目的已核实事实。它们可帮助理解版式，不应自动进入新的品牌资料或公开模板。

竖向图像约 2550/2551 × 3437 像素，文件标注 300 dpi；这不等于严格 A4，也不能证明裁切框、出血或最终印刷状态。横展和封套图同样不能单靠像素推导折页规格或刀模。重制时根据目标尺寸建立页面，不将原 JPEG 拉伸后宣称可直接送印。

## 本 Skill 增加的可复用机制

业务色登记、模块编号、正反面版本配对、客户组合单、独立补印与阶段验收是为持续维护增加的方法。它们不是原稿中已被验证存在的管理流程，也不是对某个历史品牌现状的描述。
