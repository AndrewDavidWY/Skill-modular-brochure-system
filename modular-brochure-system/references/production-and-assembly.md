# 印刷、装配与版本交付

## 制作参数先落表

将内页和封套分为两个生产项目，记录“已确认值 / 设计暂定值 / 待确认值”。只交策划时不需要补齐所有生产参数。

| 内页 | 封套 |
| --- | --- |
| 裁切尺寸、方向、出血、安全区域 | 闭合尺寸、展开尺寸、脊宽、刀模 |
| 正反面配对、翻转方向、印刷色彩 | 折线、口袋、粘口、遮挡区域 |
| 纸张、克重、表面处理、数量 | 纸张、表面处理、收纳厚度、数量 |
| 输出配置、字体与素材要求 | 刀线图层与印刷图层交付方式 |

默认内页成品为 A4 210 × 297 mm，封套需留足放入和取出的空间，按实际纸张厚度和印厂结构确定。不要从 A4 纸张尺寸推定封套尺寸，也不要凭屏幕效果承诺能容纳多少张。

无印厂规格时，出血与安全区可以给暂定设计建议，但应明确数值尚待确认，不能称为通用强制规范。若暂用四边 3 mm 出血，A4 的含出血范围为 216 × 303 mm，裁切尺寸仍为 210 × 297 mm；正式交付按供应商要求调整。

## 输出与检查

1. **内容**：复核名称、范围、参数、数字、价格、语种与联系信息；将所有占位内容移出正式成品。案例和 Logo 依照本项目可使用的证据与素材处理。
2. **尺寸**：检查 PDF 裁切框及出血框，背景延伸至规定出血边界，正文位于安全范围。封套依照已确认刀模，明确刀线不作为普通画面印出。
3. **字体和素材**：检查缺字、字体缺失、链接丢失、文字溢出；图片按实际放置尺寸检查有效分辨率。JPEG 的 dpi 标注本身不保证清晰度。按供应商要求嵌入字体或另交适当版本，并保留可编辑原稿。
4. **色彩**：使用供应商要求的色彩配置、专色定义及输出方式。转换后查看浅色文字、细线、渐变、透明与叠印效果。RGB 预览色不能代替纸张上的打样。
5. **双面**：每张的前后编号、名称、色系与版本一致，正反顺序清楚。竖版通常可从长边翻转开始试样，实际以设备设置和实物结果为准；不得直接宣称翻转方向已通过。
6. **文件**：独立模块通常交正面、背面两页的 PDF；若印厂要求分面文件或生产拼版则按其规格准备。电子组合 PDF 供阅读，需另标明是否可用于生产。
7. **实物**：按 100% 实际尺寸打印并翻面检查，确认裁切后的边距、最小文字与二维码可用性。放入封套，检查口袋遮挡、取出顺畅、闭合与装载厚度。未做实物验证就记录未验证。

印厂要求 PDF/X 时按其接受的标准和输出配置制作，并通过相应检查；文件名带有 PDF/X 或选择某个预设不足以证明整份资料合格。裁切标记、套准标记等按供应商要求输出，不默认全加。

上述输出项目可参照 Adobe 官方说明：[印刷 PDF 的输出步骤](https://helpx.adobe.com/ph_fil/indesign/desktop/print/print-production-and-file-creation/produce-print-ready-pdf-files.html)、[PDF 导出中的出血与色彩配置](https://helpx.adobe.com/lt/indesign/desktop/save-export-and-publish/adobe-pdf-export-options.html)、[印前检查中的文字溢出、字体与图像问题](https://www.adobe.com/learn/indesign/web/document-checklist-for-print-share)。使用其他排版软件时检查同样的交付结果，无需改用 InDesign。

## 客户组合单

一份组合单记录以下内容即可：

| 字段 | 示例（虚构） |
| --- | --- |
| 对象与目的 | 初次了解服务的客户，判断是否安排需求沟通 |
| 封套 | 通用品牌封套 v1.0；实际容纳量待样品确认 |
| 整张模块与顺序 | 概览 OVW-01 v1.0 → 服务 SVC-01 v1.0 |
| 选择理由 | 先理解整体范围，再查看相关服务细节 |
| 必须配套/不纳入项 | 无强制依赖；不放与需求无关的产品 |
| 数量与检查 | 按实际分发量填写；两张均检查正反完整与版本 |

可为不同受众建立标准组合，再按具体需求调整。不要把模块登记表的行顺序当成所有客户的固定全册页序。超过封套容量时应减少无关模块或调整收纳方案。

## 版本与补印

- 封套版本独立于模块版本，只有品牌或结构变化才需要更新封套。
- 模块任一面变更，重新核对两面并形成一套新发行版本；旧文件仍需能区分，旧库存状态可记“在用 / 耗尽后替换 / 停用”。
- 已停用或事实失效的库存不因节省成本继续混发。组合单引用明确的版本，避免旧正面配新背面。
- 根据模块需求与更新频率分别询价和补印。分别统计封套数量、各模块整张数量及组合包数量；一张双面纸是两面但仍是一张，不将“页数”直接当作纸张数。
- 交付登记表、源文件、预览、生产文件（若在范围内）和实际检查结果。样张、打样或印厂确认未发生时，保留清楚的待确认状态。
